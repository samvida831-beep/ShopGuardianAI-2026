# ShopGuardian Assistant

Build a premium desktop-style UI for my application called ShopGuardian AI.

I have attached a UI reference image. Use it only as inspiration for the visual style and layout. Create a unique, polished design with the same soft, friendly aesthetic rather than copying it exactly.

About the Project

ShopGuardian AI is an AI-powered smart shop monitoring system.

The backend is already complete using Python + YOLOv8 + OpenCV.

The frontend should only display data from the backend.

The application is designed for small shop owners, including users with little or no technical knowledge.

The interface should feel welcoming, simple, and trustworthy.
